# 湘雅三医院 · 出图工具平台（医图云 Medichart Cloud）

医学科研在线出图平台的交互原型，单文件 HTML（无需构建，浏览器直接打开 `index.html` 即可）。

## 目录说明

- `index.html` —— 平台原型主文件（内联 CSS / JS，含首页、工具中心、14 个工具使用页、个人中心、充值等）。
- `demo/` —— 工具详情页默认展示的示例演示图（matplotlib 预生成，14 张）。
- `assets/qr/` —— 页脚「联系我们」区域的企业微信 / 客服二维码图片。

## 功能模块

- 首页：平台介绍、工具分类导航、热门工具推荐、常见问题。
- 工具中心：基础绘图 / 基础组学 / 统计分析 / 遗传分析，共 14 个工具，卡片带真实图表缩略图。
- 工具使用页：左侧参数配置 + 数据格式说明/示例数据，右侧图表预览（默认展示示例图）与「操作说明 / 举例 / 常见问题」，支持 PNG / TIFF / SVG / PDF 导出按钮。
- 个人中心 / 充值：预付费余额模式，按次计费。

> 说明：当前为原型演示版本，二维码与数据均为示例内容。
